# dont-know-what-is-this

我的第一个 GitHub 仓库，2026-11-24 建。

## 已经学会的四步

| 命令 | 作用 | 比喻 |
|---|---|---|
| `git status` | 看改了什么 | 低头看桌上有什么 |
| `git add .` | 把改动放进待提交区 | 装盒 |
| `git commit -m "说明"` | 拍一张快照 | 封箱贴标签 |
| `git push` | 传到 GitHub | 寄出去 |

## 还没学的

- 分支（branch）：开一条平行线，试错不弄脏主线
- 回退（`git log` / `git reset`）：时间机器
- 冲突（conflict）：两个人改同一行时，Git 让你选
